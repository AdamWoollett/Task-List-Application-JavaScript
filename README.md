# Task List Application

## Overview
- This application allows a user to add custom tasks to a list where they are displayed and can be managed.
- Tasks can have any name the user inputs into the text submission box.
- A submitted tasks can have its name edited via the text input box displayed alongside the task in the Created Task List.
- A submitted task can be marked as completed using the accompanying checkbox. This checkbox can be toggled to mark the task as incomplete again if desired.
- A task can be removed from the Created Task List using the "Remove Task" button.
- These functions allow a user to easily customise and keep track of tasks added to the list.

A preview of what this project looks like when deployed can be viewed on Vercel at this link: https://task-list-application.vercel.app/<br />
(Tasks added to the list are not saved between browser sessions, reloading the page will present the user with a blank task list).
